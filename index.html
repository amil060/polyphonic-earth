      How the sonification works

      Each frame of the NASA visualization is drawn into a hidden canvas and analysed pixel by pixel (192 × 96 grid). The pixel colours are converted back into data values using the visualization's own colour scale. A sweep moves from west to east once per bar. Each of the 16 slices of the map becomes a note: its value sets the pitch, how much of it contains data sets the loudness, and its position sets the stereo pan. Every note is snapped to a musical scale so the result is music, not noise. Silence means there is no data, for example land in the ocean scene.

      Built for the 2026 NASA Space Apps Challenge by team Open Guys AI (Mingachevir, Azerbaijan). Visualizations courtesy of NASA's Scientific Visualization Studio / Earth Information Center. Audio: Tone.js.
